# 🏥 MediMind AI (메디마인드) - 스마트 복약 알림 & 케어 시스템

AI를 활용하여 복약 시간을 지능적으로 알려주고, 처방전 자동 분석, 한국형 DUR(의약품안전사용서비스) 병용금기 검사 및 어르신 맞춤형 음성 안내를 제공하는 통합 복약 관리 서비스입니다.

---

## 🚀 빠른 시작 (Quick Start)

### 윈도우에서 바로 실행하기
폴더 내의 **`start_service.bat`** 파일을 더블 클릭하면 백엔드 서버가 시작되고 웹 브라우저(`http://localhost:8000`)가 자동으로 열립니다.

또는 명령 프롬프트(CMD) / 파워쉘(PowerShell)에서:
```bash
python start_service.py
```

### 테스트 실행하기
```bash
python tests/test_backend.py
```

## ✨ 핵심 기능

1. **실시간 복약 타임라인 & 카운트다운**
   - 다음 복약까지 남은 시간 초 단위 카운트다운
   - 아침, 점심, 저녁, 취침 전 시간대별 맞춤 스케줄 카드
   - 원클릭 복약 상태 처리: **[복용 완료]**, **[10분 후 알림]**, **[건너뛰기]**

2. **멀티모달 알림 (사운드 차임 + 한국어 음성 TTS)**
   - Web Audio API 기반 멜로디 알림음
   - Web Speech Synthesis 기반 한국어 육성 안내 (*"00님, 점심 식후 혈압약 드실 시간입니다."*)
   - 헤더의 **[🔊 소리 테스트]** 버튼으로 즉시 체험 가능

3. **시니어 맞춤형 고대비·큰글씨 모드**
   - 폰트 125% 확대, 고대비 딥 네이비 배경 및 황금색/흰색 텍스트
   - 56px 이상의 빅 터치 버튼으로 어르신도 손쉬운 조작

4. **AI 약봉투 / 처방전 자연어 자동 파싱**
   - 처방전 문장("타이레놀 500mg 하루 3회 3일분 식후 30분") 입력 시 복약 주기와 권장 시간대 자동 산출
   - 감기몸살약, 만성질환, 소염진통제 3종 원클릭 테스트 프리셋 제공

5. **한국형 DUR 약물 상호작용 검사기**
   - **성분 중복 (CRITICAL)**: 타이레놀 + 종합감기약 아세트아미노펜 중복(1일 4,000mg 초과 간독성) 경고
   - **병용 금기 (MAJOR)**: 소염진통제(NSAID) + 아스피린 위장관 출혈 위험 경고
   - **음식 궁합**: 자몽주스(고혈압약 CYP3A4 억제), 우유/유제품(항생제 흡수 저해), 음주 주의사항 안내

6. **AI 약사 실시간 복약 상담**
   - 복약 누락 시 **1/2 골든룰(남은 복용 간격 기준 판단)** 및 2회분 몰아먹기 절대 금지 지침 안내

## 📂 프로젝트 구조

- `.agents/skills/medication-ai-assistant/SKILL.md` : 임상 복약 가이드 및 DUR 안전성 전용 스킬
- `backend/`
  - `server.py` : 표준 라이브러리 기반 경량 HTTP REST API 서버 (Zero Dependency)
  - `db.py` : SQLite3 데이터베이스 및 시드 데이터
  - `dur_database.py` : 한국형 DUR 및 상호작용 지식베이스
  - `ai_engine.py` : 자연어 처방전 파서 및 AI 약사 상담 엔진
- `frontend/`
  - `index.html` : 반응형 웹 대시보드 및 모달 화면
  - `css/style.css` : 모던 글래스모피즘 및 시니어 모드 스타일
  - `js/app.js` : 타임라인, 카운트다운, Web Audio 차임, TTS 음성 알림
- `tests/test_backend.py` : QA 통합 테스트 스위트 (21개 테스트)
- `start_service.bat` / `start_service.py` : 원클릭 실행 런처
